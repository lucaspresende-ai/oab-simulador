# OAB Simulador 📚

Este é um aplicativo focado em resolver questões reais de provas anteriores da OAB. 

Ele possui modo Raide (Aleatório) e Treino por Disciplina, além de um painel de estatísticas de aproveitamento.

## 🛠️ Como rodar o projeto no seu computador

**1. Pré-requisitos**

Você precisará ter o **Node.js** (versão 20 ou superior) instalado na sua máquina.

**2. Instalar as dependências**

Abra o terminal dentro desta pasta e digite o comando abaixo para baixar as "peças" do motor:

`npm install`

**3. Iniciar o aplicativo**

Para abrir o aplicativo diretamente no seu navegador, rode:

`npx expo start --web`

Para abrir no celular usando o aplicativo **Expo Go** (Android/iOS), rode:

`npx expo start -c`

(E escaneie o QR Code que aparecerá no terminal).
